# Carpeta Java – APE04

Contiene el programa en Java del Sistema de Control de Estudiantes.

## Archivos
- `Estudiante.java` – Clase con atributos, constructor, getters, setters y métodos
- `Main.java` – Clase principal con registro, listado y estadísticas

## Clase Estudiante
| Elemento | Descripción |
|---|---|
| Atributos | cedula, nombre, apellido, nota1, nota2, nota3, promedio, estado |
| Constructor | Inicializa atributos y calcula promedio/estado |
| Getters/Setters | Acceso controlado a cada atributo |
| `calcularPromedio()` | Calcula el promedio de las 3 notas |
| `determinarEstado()` | Asigna APROBADO o REPROBADO |
| `mostrarInformacion()` | Imprime todos los datos del estudiante |
